# CodeAlpha-StockPortfolioTracker

##  Project Overview
- Internship Task 3 under CodeAlpha.
- Menu-driven Python application to manage a stock portfolio.
- Allows adding stocks, viewing portfolio details, saving reports, and exiting.
- Demonstrates Python concepts such as functions, lists, loops, conditionals, and CSV handling.
- Practical project showing how Python can be used for finance and data management.

##  Execution Guide
I used **Visual Studio Code** to run this project:
1. Saved the file as StockportfolioTracker.py.
2. Opened the integrated terminal (View → Terminal).
3. Executed the program with:
   python StockportfolioTracker.py
